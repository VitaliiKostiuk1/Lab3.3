# Лабораторна робота 3.3 — Серіалізація та типова трирівнева архітектура

ООП (C#), Модуль 3. **Варіант 13** (табл. 1 — «Товар», табл. 2 — «Студент»).
Рівень виконання: **«відмінно»**. Цільова платформа: **.NET 8** (BinaryFormatter у .NET 9+ вилучено).

## Запуск
```
dotnet run --project Lab33.Part1      # Частина 1 — серіалізація «Товар»
dotnet run --project Lab33.Program    # Частина 2 — меню роботи зі студентами
```
Або відкрити `Lab33.sln` у Visual Studio 2022 і обрати запускний проект.

## Частина 2 — трирівнева архітектура (варіант 13, табл. 2)
Операція: **кількість студенток-відмінниць 5-го курсу, дані беруться з файлу**.
Додаткові сутності: `Storyteller`, `Dentist`. Додаткове вміння: «готувати» (`ICook`).

```
Lab33.Program  (Program.Main → Menu.MainMenu())
      │
Lab33.PL       Menu, StudentModel                    — рівень представлення
      │
Lab33.BLL      EntityService, StudentInfo, винятки   — бізнес-логіка
      │
Lab33.DAL      EntityContext, Student (Entity),
               IDataProvider + Binary/Xml/Json/Custom — доступ до даних
```
* Залежності лише вниз: Program → PL → BLL → DAL.
* На кожному рівні **власна сутність** (`StudentModel` / `StudentInfo` / `Student`) із перетворенням на межах — менше зв'язків між рівнями.
* **Вид серіалізації та ім'я файлу** обирає користувач у Menu (пункт 1); вони передаються вниз: Menu → EntityService → EntityContext → DataProvider. Додавання нового формату = новий клас-провайдер.
* **Винятки**: DAL генерує `DataAccessException`, BLL — власні `StudentServiceException` (+ нащадки) і перетворює DAL-виняток на `StorageException`; **перехоплюються лише в Menu**.
* `EntityService` не використовує `Console`/`Stream`; `Menu` не працює з файлами.

## Припущення (за потреби змініть)
* «Відмінник» = середній бал ≥ 90 за 100-бальною шкалою (`EntityService.ExcellentGrade`). Для 5-бальної шкали поставте 4.5 і `MaxGrade = 5`.
* Кінцевий строк реалізації = дата виготовлення + термін придатності (у днях).
* Рішення написане без можливості зібрати його в середовищі розробки; перед здачею зберіть і прогляньте один раз.
